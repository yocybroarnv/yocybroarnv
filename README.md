## About Me

I am **Arnav Raj**, a BCA graduate from **Amity University Patna**, building full-stack and AI/security systems from Bihar, India.

My work sits at the intersection of:

* **Full-Stack Engineering:** React, FastAPI, Node.js, PostgreSQL, Redis, REST APIs
* **AI/ML:** LLMs, RAG, anomaly detection, XGBoost, SHAP, NLP, generative AI
* **Cybersecurity:** OSINT, threat intelligence, digital forensics, incident response, privacy-aware systems
* **Product Thinking:** MVPs, hackathons, real user problems, scalable systems

I do not build projects just to decorate a profile. I build because I keep finding problems worth solving.

## How I Think

```ascii
Problem → User Pain → MVP → Architecture → Security → Feedback → Iterate
```

I learned through hackathons that a good technical idea is not enough. A useful system must answer:

* Who is the user?
* What pain point are we solving?
* Can it work under real constraints?
* Can non-technical users understand it?
* Can it scale without becoming fragile?
* Can it be trusted?

That is why I care about **full-stack development**, **AI**, **security**, and **product thinking** together.
